# FPV Signal Trainer

Учебный VR-комплекс для операторов беспилотных летательных систем. Проект предназначен для вывода изображения FPV-симулятора с ноутбука на Meta Quest 3 и программной имитации характерных помех аналогового видеоканала.

**Статус:** проектирование и техническая проверка архитектуры. Реализация ещё не начата.

## Концепция

Студент управляет симулятором БПЛА на ноутбуке и видит изображение на виртуальном мониторе перед глазами в Meta Quest 3. Монитор остаётся перед направлением взгляда при повороте головы.

- Гарнитура: Meta Quest 3.
- Компьютер: Windows 10/11.
- Подключение: только проводное USB через Meta Quest Link.
- Приложение: Windows PCVR, кандидатный стек — Unity 6 + OpenXR.
- Захват: выбранное окно Windows; основной кандидат — Windows.Graphics.Capture.
- Отдельный APK для Quest не входит в базовую архитектуру.
- Wi-Fi, Air Link и HDMI-карты захвата не используются.

**Технический риск:** кабели USB-A–USB-C и USB-C–USB-C, качество Link и Passthrough over Link необходимо проверить на реальном оборудовании. Passthrough over Link не считается гарантированной функцией до испытания.

## Планируемые возможности

**Виртуальный монитор:** head-locked отображение, настройка размера, расстояния и положения, выбор окна симулятора.

**Аналоговые эффекты:**
- шум и рябь;
- сравнительно тонкие и редкие горизонтальные полосы;
- искажение цветов;
- красно-синее цветовое расслоение с настраиваемым смещением контуров.

Каждый эффект отключается отдельно; предусмотрен общий выключатель. Искусственные зависания, потеря кадров, задержка и цифровая блочная пикселизация не планируются.

**OSD:** настройка положения, размера, цвета, прозрачности и состава элементов; сохранение профилей. Демонстрационные значения должны быть явно обозначены как симулируемые.

**NO SIGNAL:** только при действительной потере источника или потока захвата. Чёрный кадр от симулятора не должен автоматически считаться потерей изображения.
