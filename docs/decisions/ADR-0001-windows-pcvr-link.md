# ADR-0001: Windows PCVR через Meta Quest Link

- **Статус:** Proposed — требует технического прототипа
- **Дата:** 2026-10-31

## Контекст
Нужно показывать окно FPV-симулятора с Windows-ноутбука на Meta Quest 3. Имеются USB-A–USB-C и USB-C–USB-C кабели; HDMI-карт захвата нет. Беспроводная передача не нужна. Желательно избежать отдельного Android APK.

## Решение-кандидат
Создать Windows PCVR-приложение на Unity с OpenXR и запускать его через Meta Quest Link по USB. Захват окна, обработка изображения, OSD и симуляция выполняются на ноутбуке. Link отвечает за PCVR-видеопоток и передачу tracking данных.

## Последствия

Преимущества:
- не требуется собственный USB-видеопротокол Windows → Android;
- не нужен APK для базового PCVR-сценария;
- обновления и настройки сосредоточены на ноутбуке;
- захват и эффекты можно выполнять на GPU ноутбука.

Риски:
- зависимость от Meta Quest Link и XR runtime;
- качество зависит от кабеля и USB-порта;
- VR-приложение конкурирует с симулятором за ресурсы ноутбука;
- Passthrough over Link требует отдельной проверки;
- если Passthrough обязателен, но не подходит для эксплуатации через Link, потребуется пересмотр архитектуры, возможно отдельное приложение на Quest.

## Проверки
1. Стабильность имеющихся кабелей.
2. Пропускная способность USB для Link.
3. Запуск Unity OpenXR PCVR приложения.
4. Получение head tracking.
5. Head-locked монитор.
6. Passthrough over Link.
7. Одновременная работа симулятора и VR-приложения.
8. Задержка и нагрев во время занятия.

## Условия принятия
ADR получает статус Accepted после успешного прототипа и подтверждения всех обязательных функций на целевом оборудовании. Если критические условия не выполняются, решение пересматривается до масштабной разработки.
