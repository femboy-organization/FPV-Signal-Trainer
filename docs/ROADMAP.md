# Дорожная карта

Сроки будут определены после проверки оборудования и технических рисков.

## Phase 0 — Проверка архитектуры
- Испытать все имеющиеся USB-A–USB-C и USB-C–USB-C кабели.
- Проверить USB Test и стабильность Quest Link.
- Запустить минимальное Unity PCVR/OpenXR приложение.
- Проверить head tracking и head-locked панель.
- Захватить окно основного FPV-симулятора.
- Отдельно проверить Passthrough over Link.

**Результат:** отчёт испытаний и принятое архитектурное решение.

## Phase 1 — PCVR Monitor Prototype
- Настроить Unity и OpenXR.
- Запускать приложение через Quest Link.
- Выбирать окно Windows.
- Выводить его на виртуальный монитор.
- Настраивать размер и положение.
- Показывать состояние источника.

**Результат:** первый alpha-прототип.

## Phase 2 — Видеотракт
- Обработать закрытие окна и смену разрешения.
- Реализовать восстановление захвата.
- Минимизировать копирование текстур.
- Измерить задержку и FPS.
- Профилировать CPU/GPU.

**Результат:** стабильный монитор для выбранных симуляторов.

## Phase 3 — OSD Editor
- Реализовать элементы OSD.
- Перемещение, размер, цвет, прозрачность.
- Профили JSON.
- Маркировку симулируемых значений.

**Результат:** редактор OSD.

## Phase 4 — Analog Signal Engine
- Шум и рябь.
- Тонкие редкие горизонтальные полосы.
- Цветовые искажения.
- Красно-синее расслоение.
- Независимые и общие переключатели.
- Проверка нагрузки GPU.

**Результат:** согласованные аналоговые эффекты без искусственных фризов.

## Phase 5 — Scenario Manager
- Профили OSD и помех.
- Сохранение/загрузка.
- Импорт/экспорт.
- Версионирование формата настроек.

**Результат:** учебные профили.

## Phase 6 — Passthrough и эргономика
- Проверить Passthrough over Link.
- Оценить видимость клавиатуры/мыши/пульта.
- Проверить комфорт и читаемость.
- Определить резервный сценарий, если Link не подходит.

**Результат:** подтверждение пригодности для аудитории либо пересмотр архитектуры.

## Phase 7 — Стабилизация
- Длительные тесты.
- Диагностика и обработка ошибок.
- Упаковка Windows-приложения.
- Инструкции преподавателя и студента.
- Проверка лицензий компонентов.

**Результат:** Release Candidate.

## Phase 8 — Version 1.0
Релиз после прохождения критериев технического задания и проверки целевой конфигурации ноутбук + кабель + Quest 3.

## Возможности после 1.0
Редактор временных последовательностей помех, преподавательские сценарии, блокировка параметров, внешние телеметрические источники при наличии согласованного протокола, дополнительные языки.
