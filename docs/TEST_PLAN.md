# План тестирования

## Цель
Проверить функции, производительность и надёжность на целевой связке Windows-ноутбук + USB + Meta Quest 3. Численные цели задержки и FPS фиксируются после первого прототипа.

## Матрица оборудования
Для каждого прогона записывать модель ноутбука, CPU/GPU/RAM, Windows и драйвер GPU, модель Quest и версию ПО, версию Meta Quest Link, кабель и порт, результат USB Test, версию приложения/commit и симулятор.

## XR и подключение

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| XR-01 | Quest подключён до запуска | XR-сессия запускается |
| XR-02 | Quest не подключён | Понятное сообщение, приложение не падает |
| XR-03 | Кабель отключён во время работы | Потеря сессии обнаруживается |
| XR-04 | Link восстановлен | Восстановление или понятная инструкция |
| XR-05 | Поворот/наклон головы | Панель остаётся перед взглядом |
| XR-06 | Изменение размера панели | Корректное отображение |
| XR-07 | Passthrough over Link | Отдельный pass/fail и запись ограничений |

## Захват окна
- Выбор окна симулятора.
- Закрытие окна и повторный выбор.
- Изменение разрешения.
- Чёрный кадр как нормальное содержимое.
- Сворачивание окна.
- Эксклюзивный полноэкранный режим.
- Восстановление после ошибки захвата.

## Эффекты
Для каждого эффекта проверить включение, выключение, диапазон интенсивности, комбинации и сброс:
- шум и рябь;
- тонкие редкие горизонтальные полосы;
- цветовые искажения;
- красно-синее расслоение.

Проверить, что индивидуальный выключатель не отключает остальные эффекты, общий выключатель отключает все, а помехи не вызывают NO SIGNAL.

Цифровая пикселизация, фризы, потеря кадров и искусственная задержка не являются функциями первой версии и не тестируются как требования.

## OSD и профили
Проверить добавление/удаление, перемещение, размер, цвет, прозрачность, включение элементов, сохранение/загрузку, сброс, повреждённый JSON и маркировку демонстрационных значений.

Проверить, что OSD проходит через эффекты в согласованном порядке.

## NO SIGNAL
Проверить реальные причины: закрытие окна, остановка захвата, недоступность источника, отсутствие новых кадров дольше установленного порога.

Проверить отсутствие ложного NO SIGNAL на чёрном кадре, тёмной сцене и при включённых эффектах.

## Производительность и длительная работа
Измерять частоту кадров источника и захвата, частоту VR-рендеринга, end-to-end задержку, CPU/GPU, время шейдеров, память, температуру, разряд батареи и обрывы сессии.

Минимум один тест должен покрывать типичную длительность занятия. Критерии pass/fail согласовать с техникумом.

## Отчёт
Для каждого теста указывать ID, дату, версию/commit, конфигурацию, шаги, pass/fail, логи и связанные Issues. Не публиковать персональные данные студентов и закрытую информацию техникума.
