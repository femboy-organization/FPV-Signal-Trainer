# v0.2.0-alpha.1

**Тип:** тестовый GitHub Pre-release  
**Платформа:** Windows x64  
**Основа:** нативное приложение C++20 / OpenXR / Direct3D 11.

## Что добавлено

- Создание OpenXR instance и получение HMD system.
- Запрос требований XR runtime к Direct3D 11.
- Выбор GPU-адаптера по LUID, возвращённому OpenXR runtime.
- Создание D3D11 device и OpenXR session.
- Создание reference space VIEW.
- Создание OpenXR swapchain и D3D11 render target views.
- HLSL тестовая панель с цветными полосами, сеткой и прицельным маркером.
- Отправка панели через XrCompositionLayerQuad в пространство VIEW — панель должна оставаться перед направлением взгляда.

## Что проверить

1. Запустить Meta Quest Link и подключить Quest 3 по USB.
2. Убедиться, что Meta Quest Link выбран активным OpenXR runtime.
3. Запустить FPVSignalTrainer.exe.
4. Если приложение успешно создаст сессию, надеть гарнитуру и войти в Quest Link.
5. Проверить, появляется ли тестовая панель перед глазами и следует ли за поворотами головы.

## Ограничения

- Это первый VR-рендер-прототип, не окончательный FPV-монитор.
- Захват окна симулятора ещё не реализован.
- OSD, эффекты аналоговых помех, сохранение профилей и пользовательские настройки панели ещё не реализованы.
- Passthrough over Link отдельно не проверен.
- GitHub Actions проверяет Windows-компиляцию и unit-тесты, но не может проверить реальную гарнитуру. Функциональность XR требуется подтвердить на Meta Quest 3.
