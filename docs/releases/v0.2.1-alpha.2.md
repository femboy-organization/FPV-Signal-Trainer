# v0.2.1-alpha.2

**Тип:** GitHub Pre-release  
**Платформа:** Windows x64  
**Назначение:** тестовый релиз с автоматическим восстановлением зависимостей и первым OpenXR VR-панельным прототипом.

## Автоматическая загрузка библиотек

- Добавлен scripts/build.ps1 для локальной сборки одной командой.
- Скрипт скачивает полный pinned checkout vcpkg по baseline из vcpkg.json.
- vcpkg bootstrap выполняется автоматически.
- Сторонние C++ зависимости устанавливаются из manifest.
- Добавлен локальный binary cache, сохраняющий собранные пакеты между запусками.
- GitHub Actions кэширует vcpkg binary packages и устанавливает manifest dependencies перед CMake.
- В CI проверяются configure, build, CTest и упаковка Windows ZIP.

## VR-функции

- OpenXR instance/system/session.
- Direct3D 11 graphics binding с выбором DXGI adapter по требованиям OpenXR runtime.
- VIEW reference space.
- D3D11 swapchain.
- HLSL тестовая панель, выводимая через quad composition layer.

## Локальная сборка исходников

Требуется Visual Studio 2022 с workload Desktop development with C++ и Windows SDK. Из корня репозитория:

    powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

Скрипт автоматически скачает vcpkg, восстановит библиотеки, соберёт Release и запустит тесты.

## Внешние требования для запуска VR

Meta Quest Link / Meta PCVR OpenXR runtime не является C++ package и не включается в ZIP. Его нужно установить отдельно, подключить Quest 3 по USB и выбрать Meta Quest Link активным OpenXR runtime.

## Ограничения этой alpha

Захват окна симулятора через Windows Graphics Capture, OSD Editor, пользовательские профили и аналоговые эффекты пока не реализованы. GitHub Actions проверяет компиляцию и unit tests; реальная работа VR требует отдельного теста на Meta Quest 3.
