# v0.2.1-alpha.1

**Тип:** GitHub Pre-release  
**Платформа:** Windows x64  
**Назначение:** тестирование первого нативного OpenXR VR-панеля и автоматического восстановления C++-зависимостей.

## Изменения

- Добавлен PowerShell bootstrap/build script: scripts/build.ps1.
- Скрипт автоматически загружает закреплённую версию vcpkg, устанавливает manifest dependencies, собирает приложение и запускает тесты.
- GitHub Actions кэширует бинарные пакеты vcpkg, устанавливает зависимости отдельным шагом и затем выполняет CMake/MSVC/CTest.
- Добавлена документация по зависимостям и границам автоматической установки.
- Используется x64-windows-static и статический MSVC runtime, чтобы минимизировать внешние DLL-зависимости приложения.

## Требования

Для сборки исходников нужен Visual Studio 2022 с workload Desktop development with C++ и Windows SDK. Скрипт автоматически скачает vcpkg и зависимости проекта.

Для запуска VR-функций необходим установленный Meta Quest Link с выбранным активным OpenXR runtime. Meta runtime не распространяется через vcpkg и не включается в ZIP приложения.

## Сборка из исходников

Из корня проекта выполнить:

    powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

## Что входит в тестовую версию

OpenXR instance/system/session, D3D11 graphics binding, swapchain и head-locked HLSL test panel. Не входят захват окна симулятора, OSD editor и аналоговые эффекты. Требуется аппаратная проверка на физической Meta Quest 3.
