## Изменения относительно alpha.1

- Запрос OpenXR по базовой версии API 1.0.0 для повышения совместимости runtime.
- При создании OpenXR instance включается `XR_KHR_D3D11_enable`, если runtime объявляет его доступным.
- Quad composition layer больше не проверяется как отдельное extension: соответствующий тип слоя входит в OpenXR 1.0 core.
- Диагностическое окно показывает конкретный код и название ошибки OpenXR, а также рекомендации по проверке активного runtime Meta Quest Link.
- Увеличена высота диагностических строк для отображения расширенных сообщений.
- Исправлена конфигурация CMake/MSVC Runtime, чтобы она совпадала со статическими vcpkg-зависимостями.

## Проверки CI

Для исходного коммита прошли:
- CMake configure;
- MSVC Windows x64 build;
- CTest;
- упаковка ZIP-артефакта.

Сборка не проходила проверку на физической Meta Quest 3. Эта версия проверяет создание OpenXR instance и наличие D3D11 extension, но ещё не создаёт XR session, swapchain или виртуальный монитор.

## Инструкция для тестирования

1. Установить и запустить Meta Quest Link.
2. Подключить Quest 3 по USB и запустить Link.
3. В Meta Quest Link открыть Settings → General → OpenXR Runtime и выбрать Set Meta Quest Link as active.
4. Запустить FPVSignalTrainer.exe.
5. Проверить строку OpenXR и прислать её полный текст, если ошибка сохраняется.
