# Техническое задание FPV Signal Trainer

**Статус:** Draft.  
**Платформа:** Windows 10/11 x64 + Meta Quest 3.  
**Стек:** C++20, Win32, OpenXR, Direct3D 11, HLSL, Windows.Graphics.Capture, CMake.

## 1. Назначение

Нативное Windows PCVR-приложение для вывода окна FPV-симулятора на виртуальный монитор Meta Quest 3 и программной имитации визуальных особенностей аналогового видеоканала. Приложение не генерирует реальные радиопомехи и не взаимодействует с физическим RF-трактом.

## 2. Подключение

- Только USB через Meta Quest Link.
- Имеющиеся USB-A–USB-C и USB-C–USB-C кабели проверяются на фактическую скорость и стабильность.
- Wi-Fi, Air Link и HDMI capture cards исключены.
- Отдельный Quest APK не входит в базовую архитектуру.

## 3. Функциональные требования

### FR-01. OpenXR и диагностика
Приложение запускается как Windows x64 desktop application, проверяет OpenXR runtime, D3D11 device и сообщает о недоступности гарнитуры без аварийного завершения.

### FR-02. Виртуальный монитор
Изображение на плоской панели перед пользователем. Целевой режим — quad composition layer в VIEW space, остающийся перед взглядом при поворотах головы. Настраиваются размер, расстояние, X/Y position, предусмотрено центрирование.

### FR-03. Захват окна
Выбор окна Windows через Windows.Graphics.Capture. Кадры передаются в GPU pipeline как D3D11 textures. Обрабатываются закрытие окна, изменение размера и потеря потока. DXGI Desktop Duplication — резервный вариант.

### FR-04. Passthrough
Желаемая функция для видимости клавиатуры, мыши и рабочего места. Passthrough over Link требует испытания на целевом Quest и версии Link. Если функция обязательна для техникума, она является блокирующим критерием архитектуры до успешной проверки.

### FR-05. Аналоговые эффекты
- Шум и рябь: плотность, масштаб, скорость и интенсивность.
- Горизонтальные полосы: тонкие и сравнительно редкие; частота, толщина, контраст и интенсивность.
- Искажение цветов: тон, насыщенность и контраст.
- Красно-синее цветовое расслоение: встречное смещение контуров, X/Y offset и интенсивность.

Каждый эффект имеет независимый переключатель, есть общий выключатель, эффекты комбинируются.

Не реализуются цифровая блочная пикселизация, искусственные фризы, frame drops и artificial latency.

### FR-06. OSD Editor
Настройка состава, позиции, размера, цвета, прозрачности и выравнивания элементов. Начальный набор: TIMER, RSSI, VOLTAGE, CHANNEL, MODE, LINK QUALITY. Профили сохраняются в JSON. Данные без реального телеметрического источника помечаются simulated/manual. OSD компонуется до помех.

### FR-07. NO SIGNAL
Появляется только при подтверждённой потере capture source или frame stream. Чёрный кадр не является достаточным условием. Эффекты не вызывают NO SIGNAL. После восстановления источника изображение возвращается без перезапуска, если это технически возможно.

### FR-08. Профили
Сохранение и загрузка настроек монитора, OSD и эффектов в версионируемом JSON. Повреждённый файл не должен приводить к падению.

## 4. Нефункциональные требования

- C++20, MSVC x64, CMake, vcpkg.
- OpenXR + Direct3D 11.
- GPU-пайплайн и минимизация копирования текстур.
- XR frame loop не блокируется ожиданием кадра захвата.
- Искусственная задержка не добавляется; фактическая задержка измеряется.
- Цели FPS/latency фиксируются после испытаний на целевом ноутбуке.
- Типичная длительность занятия без критического сбоя.
- Русский язык интерфейса первой версии.

## 5. Критерии приёмки

1. Quest 3 работает через USB Link с утверждёнными кабелями.
2. Нативное приложение создаёт OpenXR session.
3. Выбранное окно симулятора отображается на VR-панели.
4. Панель остаётся перед взглядом.
5. Положение и размер настраиваются.
6. Четыре типа согласованных эффектов работают и отключаются.
7. OSD редактируется и сохраняется.
8. NO SIGNAL возникает только при реальной потере источника/потока.
9. Чёрный кадр не вызывает ложную потерю.
10. Passthrough проверен, если обязателен для занятий.

## 6. Не входит в первую версию

Wi-Fi/Air Link, HDMI capture cards, отдельный APK, реальные RF-помехи, автоматическая телеметрия полётного контроллера, пикселизация, зависания, искусственная потеря кадров и задержка.
