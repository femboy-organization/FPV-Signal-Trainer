# Политика безопасности

## Поддерживаемые версии
Программных релизов пока нет. После выпуска стабильной версии таблица поддержки будет добавлена сюда.

## Сообщение об уязвимости
Не публикуйте сведения об уязвимости, пароли, токены, персональные данные или закрытые сведения техникума в открытом Issue.

Предпочтительный канал — GitHub Private Vulnerability Reporting, если он включён для репозитория. Если функция недоступна, свяжитесь приватно с владельцами репозитория через GitHub.

В отчёте укажите затронутый commit/версию, условия воспроизведения, потенциальное влияние и безопасный способ связи. Не прикладывайте реальные данные учащихся.

## Область внимания
- безопасная обработка окон и кадров сторонних приложений;
- проверка пользовательских OSD-профилей;
- отсутствие секретов в логах;
- контроль сторонних пакетов и ресурсов;
- явное различение симулируемых и реальных телеметрических данных.
