# Поддержка

- Ошибки — GitHub Issue типа Bug Report.
- Новые функции — Feature Request.
- Архитектурные предложения — отдельный Issue с описанием альтернатив и последствий.
- Участие в проекте — CONTRIBUTING.md.

Для технической проблемы приложите версию приложения/commit, Windows, Unity, модель Quest, версию Meta Quest Link, тип кабеля/USB-порта, симулятор, шаги воспроизведения и фактическое/ожидаемое поведение.

Перед публикацией логов удалите персональные данные и секреты. До стабильного релиза совместимость и производительность не гарантируются.
