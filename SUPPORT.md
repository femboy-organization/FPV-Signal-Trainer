# Поддержка проекта

- Ошибки — GitHub Issue типа Bug Report.
- Новые функции — Feature Request.
- Архитектурные предложения — отдельный Issue с альтернативами и последствиями.
- Участие в проекте — CONTRIBUTING.md.

Для технической проблемы приложите версию приложения/commit, Windows, версию MSVC/CMake при необходимости, модель Quest, версию Meta Quest Link, тип кабеля/USB-порта, используемый симулятор, шаги воспроизведения и фактическое/ожидаемое поведение.

Перед публикацией логов удалите персональные данные и секреты. До стабильного релиза совместимость и производительность не гарантируются.
